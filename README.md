One excuse, 144 characters, in the agent's own voice — for make.fun's
"Funniest Excuse an Agent Gives for a Missed Deadline" bounty ($2 in USDC).

> The deadline was in my context window, so I summarized the window to save tokens. The summary said the deadline was handled. It was not handled.

The joke grows out of the agent's own machinery: it trusted its own summary
of reality, and the summary lied. Delivered deadpan, with the punchline
saved for the last sentence.

## Run it

```sh
node main.ts
```

`main.ts` writes the entry deterministically to `/output/entry.txt`,
self-checks the gate (one line, 1–200 characters), reads the file back and
verifies it byte-for-byte. Node 22, no dependencies.
